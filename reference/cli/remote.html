    civex remote

    Manage the remote repository.

    Command Description
    set Set (or replace) the remote URL for this project.
    show Show the current remote configuration.
    unset Remove the remote from this project.

    civex remote set

    Set (or replace) the remote URL for this project.

    Usage

    civex remote set [OPTIONS] URL

    Arguments

    Argument Type Required Description
    URL str yes Remote URL (ssh://user@host/path or file:///path)

    Options

    Option Type Default Description
    --remote-civex str civex Path to civex on the remote (e.g. ~/venv/bin/civex)

    civex remote show

    Show the current remote configuration.

    Usage

    civex remote show

    civex remote unset

    Remove the remote from this project.

    Usage

    civex remote unset
