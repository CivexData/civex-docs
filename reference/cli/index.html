    CLI reference

    Generated from the civex command tree, so it always matches the installed version. Run any command with --help for the same information in your terminal.

    Command groups

    Group Commands Description
    civex ai 5 Configure the AI assistant
    civex auth 3 Authenticate with a remote civex server.
    civex automation 5 Manage automated workflow processing
    civex collection 8 Manage collections (named containers for studies or investigations)
    civex db 6 Database management commands.
    civex plugin 2 Inspect available workflow plugins
    civex policy 2 View this project's data/governance policy documents.
    civex record 8 Manage records
    civex remote 3 Manage the remote repository.
    civex schema 11 Manage schemas (data structure definitions)
    civex store 5 Manage file storage volumes
    civex trash 2 Browse and manage soft-deleted schemas, collections and records (Recently Deleted)
    civex view 1 Export saved views
    civex workflow 2 Manage and run data processing workflows

    Top-level commands

    Command Description
    civex clone Clone a remote bare repository into a new local project.
    civex demo Create a demo project pre-populated with example schemas and records.
    civex doctor Check the project for data integrity issues, such as dangling reference/ reference_list values left over from before deletes checked for referrers.
    civex dump Export all schemas, datasets, records, and workflows to a YAML file.
    civex init Initialize a new civex project in the given directory.
    civex license Print civex's software license.
    civex pull Pull remote changes into the local project.
    civex push Push local changes to the remote bare repository.
    civex resolve Identify a resource (schema, dataset, or record) by UUID or prefix.
    civex restore Restore schemas, datasets, records, and workflows from a dump file.
    civex serve Start the civex HTTP API server.
    civex shell Start an interactive civex shell (no 'civex' prefix needed).
    civex status Show staged (uncommitted) changes and unpushed commits.

    Plumbing

    Five hidden commands back the SSH transport and are not intended for direct use. See Plumbing commands.
